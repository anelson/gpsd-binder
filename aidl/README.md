# Frozen AIDL API: android.hardware.gnss, version 2 (Android 13)

These files are the frozen version 2 snapshot of the `android.hardware.gnss`
AIDL interface, copied unchanged from the LineageOS 20 source tree at
`hardware/interfaces/gnss/aidl/aidl_api/android.hardware.gnss/2/`.
`.hash` is the frozen interface hash, which `build.rs` stamps on every
generated interface together with version 2, as AOSP's build does.

They come from the Android Open Source Project and are licensed under the
Apache License, Version 2.0; each file keeps its original header. Do not edit
them: Android checks the version and hash a driver reports.

A driver for a newer Android release may need a newer frozen version
(`aidl_api/android.hardware.gnss/<N>/`) next to or instead of this one.
